# Roadmap

This roadmap lists possible future work for BubblePlug. Priorities and scope may
change based on user feedback and development capacity.

## Plugin support

- Add VST2 plugin discovery and loading.
- Add CLAP plugin discovery and loading.
- Add Audio Unit and Component support, including AUX/Component classification
  where applicable.
- Improve plugin format classification and plugin-family variant handling
  across supported formats.

## Mixer and host integrations

- Show the real plug-in preset name in Mixer when the host or plug-in makes it
  available.
- Investigate a Logic Pro edition or integration and define its feature scope
  and macOS compatibility requirements.
- Investigate a Windows edition, including a Windows-native host integration
  and installer.

## Plugin artwork

- Explore an opt-in community artwork index with exact plugin identity,
  moderation, and copyright and privacy safeguards.

## Distribution

- Automate macOS release builds and attach packages and checksums to GitHub
  Releases.
- Gather compatibility reports across macOS versions, Ableton Live versions,
  and Apple Silicon models.
